Plately Meta oEmbed Review

Public test page for the Instagram oEmbed use case in Plately.

Use Case

Plately lets users import a recipe from a public Instagram post or reel. The backend calls the official instagram_oembed endpoint to read the public caption, author, embed HTML, and thumbnail. Plately then extracts recipe fields so the user can review and save the recipe.

No Instagram login credentials are stored by Plately. The test flow works with public Instagram content only.

Default test content: https://www.instagram.com/p/DYUySvaI9X9/. This page also accepts another public Instagram URL as ?ig=....

Before Meta oEmbed approval is granted, the endpoint may return Meta error (#10) Meta oEmbed Read must be reviewed and approved. That is the permission being requested. Once approved, the same flow returns oEmbed metadata for public Instagram content.

Ready

Paste the public Instagram URL from the review notes and click "Check oEmbed".

Reviewer Steps

  1. Open this page: https://app.plately.nl/meta-oembed-review.html.
  2. Use the prefilled public Instagram test URL, or paste another public Instagram post/reel URL.
  3. Click Check oEmbed. A successful response shows provider, author, thumbnail status, and embed HTML status.
  4. Click Open Plately Import Flow. The app opens with the same Instagram URL prefilled and starts the import flow.
  5. After import, Plately shows the recipe review screen with title, ingredients, and preparation steps where available.
